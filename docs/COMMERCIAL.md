## 2. 中文小独立站人民币付款：通行做法全景

### 2.1 微信支付 / 支付宝官方商户（正道，门槛最高）

- 开通门槛（综合多份 2026 年商家指南，签约前以官方入驻页为准）：
  - 主体：**必须有营业执照**，个体工商户或企业均可；**个人身份不能开通交易类支付**。
  - 材料：营业执照、法人身份证、结算账户（个体户可用法人对私账户，企业需对公账户）、
    经营类目与交易场景说明。
  - 备案：国内服务器部署的交易站需完成 **ICP 备案**（域名 + 主体 + 服务器托管信息，
    常规 3–7 个工作日）；仅自营卖货无需另办 EDI 等增值电信资质。
  - 认证：服务号 / 小程序认证费约 ¥300 / 年（个体户有优惠说法不一，以官方为准）。
  - 审核：商户号申请约 1–5 个工作日。
- 费率：微信支付约 **0.6%–1%（按类目）**；支付宝商家收款同量级（以签约类目为准）。
- 优点：用户最信任、转化率最高；回调自动开通，体验与 Metis 模式一致；资金走持牌清算，无二清风险。
- 缺点（对 Ling 是硬约束）：要求**中国大陆主体**。他在美国、持有的是**美国 LLC**，
  美国公司不能直接申请大陆微信 / 支付宝商户号；要走这条路，必须另有大陆主体
  （回国办个体户，或委托合规代办并由他本人完成法人实名），且需大陆结算账户与 ICP 备案。
- 个人收款码不是替代品：2022 年央行 259 号文后，个人静态收款码原则上不得用于远程
  非面对面经营收款；经营性收入应走商户收款码。长期用私码收经营款，收入性质不变
  （仍应申报纳税），且 2026 年已有税务大数据比对、私户收款补税罚款的公开案例。

### 2.2 聚合与个人可用通道：虎皮椒 / PayJS / 易支付类（快，但风险自担）

- 形态：平台以自有或合作商户号代收，再结算给站长；个人无需营业执照即可开通，
  上线最快，适合验证期。
- 风险（按严重程度排序，签约前逐项核实）：
  1. **二清与跑路**：资金是否经过无牌平台二次清算，是最大风险。只选能证明收款方为
     持牌支付机构、费率与结算周期写入后台可查记录的通道；凡是“先收进平台钱包、再人工
     提现、结算周期不透明”的，一律按高风险处理。
  2. **通道不稳定**：个人通道常有单通道限额、微信端仅 30 天有效等用户反馈（论坛说法，
     未经官方证实），随时可能断通道、换费率。
  3. **费率高于官方**：通常显著高于 0.6%，且可能有开通费 / 年费。
  4. **税务与合规**：钱进私户不改变应税性质；经营收入须如实申报，私户分流在 2026 年
     已是税务大数据重点扫描对象。
- 定位建议：**只作过渡桥，不作终局**。若用，须设单日 / 单笔上限、每日对账、
  保留随时切回兑换码链路的能力；量起来后必须迁移到 2.1 或 2.3。

### 2.3 创作者平台：爱发电 / 面包多 / 知识星球式（零开发，体验有折损）

- 爱发电：平台抽成约 **6%（已含微信 / 支付宝渠道费）**，创作者实得约 94%；
  按月赞助为主，无强制自动续费。面包多：官方自述平均服务费约 3%，第三方横评给出
  5.7%（闪电结算）~13% 的区间，签约前以官方费率页为准。
- 优点：零营业执照门槛、零开发、平台处理收款与提现；适合先验证“有没有人愿意付 ¥19.9”。
- 缺点（对本站是结构性折损）：
  1. 平台定性是“赞助 / 赠与”而非商品买卖，**已解锁的数字内容通常不支持无理由退款**，
     售后纠纷处理权在创作者沟通，不如自营订单可控。
  2. **无法自动开通本站报告**：平台侧付款与本站订单系统不打通，仍需人工发码
     （与现有 dtjishou 链路同构，只是换了个卖码处），“费劲”的根因没解决。
  3. 结算对象：这类平台面向大陆创作者结算；Ling 人在美国、持美国 LLC，
     能否以现有身份提现、提现到哪类账户，**需他本人向平台客服核实，本文未证实**。
- 定位建议：可作“验证有没有人付费”的零成本探针，不作终局支付方案。

### 2.4 海外通道：Stripe / Paddle / LemonSqueezy（Ling 现有条件最顺，但对大陆用户有折损）

先说结论：**这条路对“人在美国 + 有美国 LLC”的 Ling 最顺，但对“用户主要在国内”
有天然折损**，两者要分开算。

- Stripe（美国 LLC 可开）：
  - 开通：美国公司 + EIN + 美国同名银行账户；**不直接对接中国大陆主体**（大陆公司
    不在 Stripe 直接支持范围），但 Ling 的主体是美国公司，不受此限。
  - 费率（美国账户公开基础价）：2.9% + $0.30 / 笔；国际卡 +1.5%，货币兑换 +1%
    （以 Stripe 官方价目为准；Managed Payments 代缴销售税另加约 3.5%，本站单份
    数字报告是否需要，问会计师）。
  - 对大陆用户：Stripe 支持 **WeChat Pay / Alipay / UnionPay 作为付款方式**
    （面向中国消费者、经 Stripe 跨境收单，结算为美元到美国账户）。注意三点：
    ① 这是跨境收单，不是大陆本地商户号，存在汇率转换成本与钱包支付成功率折损；
    ② 用户看到的是境外商户，信任度低于微信 / 支付宝原生商户；
    ③ 仅支持已实名认证的微信 / 支付宝账户付款。
- Paddle / LemonSqueezy（Merchant of Record，代收代缴全球销售税）：
  - 费率：Paddle 约 5% + $0.50 / 笔；LemonSqueezy 约 5% + $0.50 / 笔
    （另有美国以外交易 +1.5%、PayPal +1.5% 等附加项，2026 年 10 月核对价）。
  - 对大陆用户：两者**不提供微信 / 支付宝结账**（以卡 / PayPal 为主），
    与大陆用户“扫码即付”的习惯错位；LemonSqueezy 银行打款名单无中国大陆，
    但 Ling 提现到美国账户不受此限。
  - 适用面：海外华人 / 全球市场（与 Ling 10-31 夜属意的 Fanvue 式出海方向同构），
    不是大陆用户主力通道。
- Creem 等（3.9% + $0.40 / 笔，MoR）：支持大陆卖家提现到支付宝 / 银行卡，
  但 Ling 是美国主体，不必为此绕路；仅当未来想同时覆盖大陆个人身份时再评估。

## 4. 成本账：单份 AI 报告 token 成本 vs ¥19.9

### 4.1 成本结构（以代码实测为准，不是厂商宣传）

- 调用量：完整报告 = **4 次 DeepSeek 调用**（analysis / mindmap / fortune / qa 各 1 次，
  见 `backend/app/api/ai_report.py` 的 `generate_single_module`；30 问答疑在 1 次调用内生成）。
- 关键事实：`call_deepseek_api` 目前**丢弃 API 返回的 usage 字段**，只取 content，
  因此**没有任何一单的真实 token 账单可查**。下表是估算，正式定价前必须以
  DeepSeek 控制台账单复核；同时建议后续在调用处记录 usage（不在本包范围，记入 checklist）。
- 幂等闸已存在：已生成过的模块直接读盘返回，**绝不重复烧 token**
  （前端重复点击、网络重试、恶意重放都只读盘）；但单次调用失败重试最多 3 次，
  失败重试会重复计费，属小概率附加成本。

### 4.2 估算表（DeepSeek V4.1 Flash 2026 年 9–10 月官方价目口径：峰时输入 $0.30 / 百万、
  输出 $1.20 / 百万；闲时半价。代码中模型名为 `deepseek-chat`，其与现行价目表的
  对应关系以 DeepSeek 官方页面为准；第三方价目表对同一模型给出过 $0.14/$0.28 的
  不同数字，故下表按峰时官方价取高值，结论只会更保守）

| 情形 | 输入（4 模块合计） | 输出（4 模块合计） | 峰时成本 | 折合人民币（约） |
|---|---|---|---|---|
| 基准：每模块输入 3k、输出 3k | 12k tokens | 12k tokens | $0.018 | 约 ¥0.13 |
| 5 倍：每模块输入 15k、输出 15k | 60k tokens | 60k tokens | $0.09 | 约 ¥0.65 |
| 10 倍极端：每模块输入 30k、输出 30k | 120k tokens | 120k tokens | $0.18 | 约 ¥1.31 |

（人民币按约 7.3 换算，仅为量级示意，以实时汇率为准；闲时约减半。）

### 4.3 结论：token 不是定价约束，支付费与固定成本才是

- 即使按 10 倍极端估算，token 成本约 ¥1.31，仅占 ¥19.9 的约 6.6%；基准情形不到 1%。
- 每单支付手续费（按 ¥19.9 计，量级示意）：
  - 微信 / 支付宝官方商户（~0.6%）：约 ¥0.12，净得约 ¥19.78；
